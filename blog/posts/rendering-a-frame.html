Keep the pipeline explicit

A useful rendering model separates mutable application state from the data needed to draw the next frame. That gives each stage a narrow contract and makes expensive transitions visible.

input → state → layout → paint
              ↘ cache ↗

The blog layout deliberately has no sidebars, card stacks or decorative hero. Future posts can add generated SVG, canvas or WebGL visualizations inside the same .viz boundary.
